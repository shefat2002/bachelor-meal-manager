# Financial Visualization & Async Report Handling

Specs: `docs/FRONTEND_DESIGN_OVERVIEW.md` §3.1/§3.4, `frontend/AGENTS.md` §6, `docs/SKILL_BUILDER.md` (frontend §6).

## Charts (Recharts)

- Primary chart: **daily bazar spend vs meal volume** for the active month — bar (spend) + line (meal units) combo, responsive container, resampling/scrolling for 31 days.
- All numbers in charts and axes use `tabular-nums`; currency formatted consistently (2 decimals).
- Colors follow the design tokens (skill `bmm-design-system-app-shell`): indigo for primary series, semantic emerald/rose only for surplus/arrear meaning.
- Fetch through feature hooks with month-scoped query keys (`['messes', messId, 'summary', { month, year }]` family — see `bmm-server-state`).

## Master settlement table (`/dashboard/[messId]/reports`)

High-density accounting table per design spec §3.4: Member · Total Meals · Meal Cost · Utility Share · Total Cost · Total Deposited · **Final Balance** (emerald badge for surplus, rose for arrear).

- Use a proper `<Table>` with sticky header, `tabular-nums` columns, right-aligned numerics.
- Export & Close bar: **Export PDF** button + **Lock Month** toggle — both gated by `<Authorize roles={['MealManager','SuperAdmin']}>` (skill `bmm-rbac-route-guards`). Locking must confirm (destructive-ish: freezes edits month-wide).

## Async job tracking (RabbitMQ → UI)

Monthly PDF statements are generated by a backend background job; the UI must notify on completion:

1. Subscribe to job status via **SSE/WebSocket** if the endpoint exists; otherwise fall back to **smart polling** — a `refetchInterval` on a `['messes', messId, 'jobs', ...]` query that polls only while a pending job exists (don't poll forever).
2. On completion: notification popover entry ("November settlement ready"), with a direct download action.
3. Download links carry auth (fetch as blob via the API client with Bearer header — not a bare `<a href>` that leaks no-token 401s).

## Gotchas

- Never render money math derived on the client from raw rows — display the server-computed summary (equations live in Orleans, root `AGENTS.md` §4).
- Handle empty-month states (no meals logged → friendly empty chart, not a broken axis).
- Notifications must not require a refresh: wire the SSE/poll into the notification popover on app shell mount.
